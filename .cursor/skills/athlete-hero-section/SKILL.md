# Athlete Hero Section

## Instructions

1. Include athlete name, discipline, and mission in first viewport.
2. Add one credibility marker (title, ranking, or major event).
3. Place dual CTA: donation and sponsorship.
4. Use one supporting visual/media block near hero content.
5. Keep copy concise and emotionally strong.

## Hero Structure

- Eyebrow (campaign context)
- Headline (athlete + ambition)
- Supporting paragraph (why now)
- CTA row (primary + secondary)
- Credibility micro-panel
