# Modern Athlete UI

## Goal
Construir páginas visualmente marcantes para atleta, com narrativa e clareza de conversão.

## Instructions

1. Start with a strong hero: athlete name, mission, primary CTA, secondary CTA.
2. Use editorial rhythm: short intro, credibility block, narrative moments, conversion block.
3. Apply dark/high-contrast palette with one accent color for priority actions.
4. Keep sections scannable: bold headings, concise text, clear spacing.
5. Use media as support to story (not as clutter).

## Design Checklist

- [ ] Hero with clear value proposition
- [ ] Visual hierarchy from top to bottom
- [ ] Strong CTA contrast
- [ ] Mobile-first readability
- [ ] Consistent spacing and typography
